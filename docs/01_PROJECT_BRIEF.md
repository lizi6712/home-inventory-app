# Project Brief

## Working name

Home Inventory App (temporary name)

## Problem

People buy household products but lack a simple way to know what they already
have, where it is stored, what expires soon, and what needs to be purchased.

## Users

Any person who registers. Each account owns a private inventory. A future
version may allow a user to invite members into a shared household.

## Primary outcome

A user can open the application on a phone and answer, within seconds:

- Do I have this product?
- How many units do I have?
- Where is it stored?
- What expires soon?
- What should I buy?

## Product principles

1. Adding or updating stock must take seconds, not minutes.
2. Unknown information stays unknown; the system must not force invented data.
3. A product and a physical stock batch are different records.
4. User data is private by default.
5. The data model must survive replacement of the UI or AI tool.
6. Start with the smallest useful product and measure real usage before adding
   automation or AI features.

## Success criteria for the MVP

- A new user can register and access only their own records.
- A user can create a product and add a stock batch.
- A user can see current quantity by product.
- A user can record consumption, disposal, purchase, and correction.
- A user can filter by category and location.
- The application highlights expiring and low-stock items.
- Core flows work comfortably on a mobile screen.
